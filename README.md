# Knowledge-Graph-and-Social-Network-Analysis

## Instructions:
1. Place code and workbook in same folder
2. Workbook must be named 'SCCAH_Workbook', must be '.xlsx' file type and follow the same formatting as the uploaded workbook. (capitalisation matters)
3. 'pandas' and 'openpyxl' must be installed on device running the code. This can be installed by opening terminal / command prompt and executing 'pip install pandas' and 'pip install 'openpyxl' respectively.
4. Code outputs will create a new folder in current location called 'sna_outputs', all results will be uploaded in said folder.

## Code outputs:
1. Included evidence item list
2. Spearman matrix
5. Five sensitivity passes outputs
6. Capability scores all passes
